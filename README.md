# 🎓 Anna University Result Server Monitor

A simple, modern and mobile-friendly web dashboard for monitoring the availability and response time of the **Anna University Result Server**.

🌐 **Live Website:**  
https://dhinakaranelango.github.io/result-server-checker/

---

## ✨ Features

- 🟢 Real-time server availability status
- ⚡ Response time measurement
- 🕐 Last checked time
- ⏱️ Automatic checking every 30 seconds
- 🔄 Manual **Check Server Now** button
- 📊 Response history for recent checks
- 🌙 Dark mode
- ☀️ Light mode
- 💾 Remembers dark/light mode preference
- 📱 Fully responsive mobile design
- 💻 Desktop and tablet friendly
- 🌐 Direct link to the Anna University Result Server
- 🚫 No backend server required

---

## 🖥️ Monitored Server

The project currently monitors:

**Anna University Result Server**

https://coe.annauniv.edu/home/index.php

---

## 📸 Dashboard

The dashboard displays:

| Information | Description |
|------------|-------------|
| 🟢 Overall Status | Current server availability |
| ⚡ Response Time | Approximate request response time |
| 🕐 Last Checked | Time of the latest check |
| ⏱️ Next Check | Countdown to the next automatic check |
| 📊 Response History | Recent response-time results |

---

## 🔄 How It Works

The website automatically checks the Anna University Result Server every **30 seconds**.

You can also manually perform a check using:

**🔄 Check Server Now**

The dashboard then updates:

1. Server status
2. Response time
3. Last checked time
4. Next check countdown
5. Response history

---

## 🌙 Dark Mode

The dashboard includes a built-in dark mode.

Click the 🌙 button in the header to switch between:

- ☀️ Light Mode
- 🌙 Dark Mode

Your selected theme is saved in your browser using `localStorage`.
